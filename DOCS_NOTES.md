# Заметки по документации

## Suvvy.ai — docs.suvvy.ai/ru

### Платформа
- Создание LLM-агентов (GPT-5, Claude 3.5 Sonnet, Gemini 3 Pro, Suvvy-GPT)
- Каналы: Telegram, WhatsApp, amoCRM, Bitrix24, Wildberries, OZON и 30+ других
- Оплата за диалог: ~7-15 руб. (простые), 15-30 руб. (сложные)

### Вебхуки (docs.suvvy.ai/ru/deistviya/veb-khuki)
- Настраиваются как "Действие" бота
- Поддерживают GET / POST / PUT / DELETE / PATCH
- Данные передаются через: URL-параметры, заголовки, тело (JSON или текст)
- **Переменные действия** — бот сам собирает нужные данные у пользователя и подставляет в запрос
- Ожидаемый статус по умолчанию: 200
- При ошибке: уведомить пользователя / остановить диалог / пропустить шаг

### Google Sheets (docs.suvvy.ai/ru/rabota-s-tablicami)
- Прямое подключение Google Sheets (авторизация через Google)
- Поиск через Dynamic SQL Generator (DSG): WHERE, LIKE, операторы сравнения
- Смысловой поиск: VECTOR_SEARCH(колонка, запрос) >= 0.5–0.8
- Предпросмотр: первые 5 строк
- Настраивается описание таблицы + описание колонок

### Мультиагентность
- Главный агент вызывает подчинённых как функции
- Рекомендуется при большом числе инструкций (снижает ошибки)
- Подчинённые специализированы: один — вебхук, другой — таблица

## PartsAPI.ru — partsapi.ru

### Общее
- RESTful API, без лимита запросов (подписка)
- База TecDoc 2025Q4
- ~428 млн кросс-ссылок
- Регистрация → личный кабинет → демо-ключ бесплатно
- Контакт: info@partsapi.ru, Telegram: @tecdoc_ru

### Ключевые методы

#### VINdecode
- Вход: `vin` (17 символов), `lang` (2 символа, напр. `ru`)
- Выход: марка, модель, двигатель, тип кузова, год производства и др.
- Тариф: от 5 000 руб./мес

#### VINdecodeOE — **основной для нашей задачи**
- Вход: `vin` (VIN или номер рамы, макс. 17 символов)
- Выход: расшифровка по оригинальным каталогам производителя
  - марка, модель, двигатель, кузов, цвет, регион, дата производства, опции
- Тариф: от 5 000 руб./мес

#### searchParts
- Вход: `query` (артикул или его часть, макс. 25 символов), `lang`
- Выход: ArticleId, ArticleNo, ArticleName, бренд, атрибуты, наличие, цена у EU-поставщиков
- Тариф: от 3 000 руб./мес

#### getCrosses — **для поиска аналогов через partsapi**
- Вход: номер детали (макс. 35 символов)
- Выход: оригинальный бренд/номер + заменяющий бренд/номер
- БД: ~428 млн кросс-ссылок
- Тариф: от 5 000 руб./мес

## Архитектура вебхука

### Запрос от Suvvy → наш вебхук
```
POST /api/vin
Content-Type: application/json

{ "vin": "Z8TXLCW6WCM902224" }
```

### Логика вебхука (Vercel Function)
1. Получить VIN
2. Запрос к partsapi VINdecodeOE → получить OEM-номер камеры заднего вида
3. Поиск по Google Sheets → список неоригинальных аналогов на складе
4. Вернуть JSON: если аналоги найдены — возвращаем их, если нет — возвращаем `found: false`

### Ответ вебхука (аналоги найдены)
```json
{
  "found": true,
  "oem": "867698501",
  "camera_name": "Камера заднего вида Toyota Camry 2018",
  "analogs": [
    { "brand": "ParkMaster", "article": "CAM-TOY-001", "price": 2500 },
    { "brand": "Digma", "article": "DCR-320", "price": 1890 }
  ]
}
```

### Ответ вебхука (аналоги не найдены)
```json
{
  "found": false,
  "oem": "867698501",
  "camera_name": "Камера заднего вида Toyota Camry 2018"
}
```

## Поведение бота при `found: false`

Прописывается в инструкции бота в Suvvy:

> Если вебхук вернул `found: false` — аналогов на складе нет.
> В таком случае ответь клиенту на основе своих знаний: перечисли
> популярные неоригинальные камеры заднего вида для данной марки/модели
> (бренды, артикулы если знаешь). Обязательно предупреди, что это
> общая информация — наличие и цену нужно уточнять отдельно.

**Итоговый сценарий:**
1. На складе есть → бот называет конкретные позиции с ценой
2. На складе нет → бот говорит «на складе сейчас нет, но вот что обычно подходит: …» и перечисляет аналоги из своих знаний
